# Ledger

Caine Road Ventures' operating platform for the Hong Kong co-sec and accounting firms it acquires (product working name: Harbourline Desk).

Start with `AGENTS.md` (project context, non-negotiables and engineering workflow rules), then `docs/PRODUCT_SPEC.md`. `CLAUDE.md` imports `AGENTS.md` so every agent reads the same rules.

- `docs/`: spec, decisions, roadmap, playbook library
- `seed/`: playbooks, requirement items, message templates, demo data (JSON)
- `prototype/`: clickable single-file prototype and walkthrough video (reference only)
